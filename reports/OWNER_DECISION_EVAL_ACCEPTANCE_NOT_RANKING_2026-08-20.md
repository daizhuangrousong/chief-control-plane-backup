# Owner Decision · Eval 是验收体系，不是排行榜

日期：2026-08-20

状态：`APPROVED / DIRECTION_AND_ACCEPTANCE_BASELINE`

## 正式定位

Eval 是通用 AI Agent 生产验收体系。它像体检一样检查单个 Agent 的交付健康：

- 完成了什么；
- 缺了什么；
- 哪里存在阻断缺陷；
- 需要多少人工返工；
- 是否能够进入下一生产环节。

## 多 Agent 的用途

GPT Researcher、Open Deep Research、`dzhng/deep-research` 是不同校准样本，用于验证同一套验收尺度能否稳定识别问题。不得据此计算综合排名、选择冠军或把报告包装成横评。

## Phase 0 性质

- 公域方法实验；
- 将抽象质量要求翻译为可执行验收步骤；
- 输出真实证据、阻断缺陷、人工返工需求和验收结论；
- 允许外部讨论、质疑与复用，沉淀方法资产；
- 不做榜单，不宣称认证，不把商业化作为成功条件。

## Case 001 目的

Case 001 仍为“新能源汽车空心电机轴制造路线决策”。目的不是比较哪个 Agent 更强，而是验证：这套体系能否发现普通研究质量分数无法表达的交付风险。

DeepResearch Bench、原子化 rubric 与 ISO/IEC 25010 只能作为方法输入；最终判定必须回到交付健康、阻断缺陷与能否进入下一环节。B0/B1/B2 阻断缺陷可以推翻表面漂亮的质量表现，但不得汇总为排行榜分数。

## 禁止表达

- 最强 Agent、冠军、胜者、排名、榜单、横评；
- 用一个综合总分替代分项证据和阻断判断；
- 把测试结果表述为认证、合规证明或行业权威结论；
- 以商业化、流量或销售结果判定 Phase 0 成败。
